# Naming the art in Figma

Every frame: **512 × 512**, transparent, the same size in every pose, feet resting at **y = 442** (like the Baby), no effects (Z's, skull, hearts) drawn in. Export as **SVG**; Figma uses the frame name as the file name.

## Per character

Replace `baby` with the character's code: `child-good`, `child-bad`, `teen-excellent`, `teen-good`, `teen-bad`, `1a` … `3d`.

| Frame name | What it shows |
|---|---|
| `tomo-baby-idle-1` | Standing |
| `tomo-baby-eat-1` | Mouth open (also used for sleeping) |
| `tomo-baby-eat-2` | Mouth closed |
| `tomo-baby-refuse` | Turning away; also mad, angry, upset |
| `tomo-baby-happy` | Big smile |
| `tomo-baby-sick` | Unwell; also sad and calling |
| `tomo-baby-look` | Looking to its left |
| `tomo-baby-look-right` | Looking to its right |

Optional, any time later: `idle-2`, `sleep`, `blink`, `sad`, `call`, `pout`, `scolded`.

The full list of shared items (food, poop, scenes, icons) is in [Animations.md](Animations.md) §5.

## The room

| File name | What it is |
|---|---|
| `tomo-room` | The room, 596 × 596, window cut out |
| `tomo-sky-morning`, `tomo-sky-day`, `tomo-sky-evening`, `tomo-sky-night` | Skies behind the window, same size |
