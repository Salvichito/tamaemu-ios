1. PURPOSE AND AUDIENCE
Tomomix is a virtual pet app. Its main feature is Tomomix, an original pet game I designed and drew myself: you catch a shooting star, it hatches into a baby, and you feed it, play with it, clean up after it and watch it grow into one of 19 characters. It is for anyone who enjoys cozy pet-raising games, especially adults who grew up with handheld virtual pets.
The app can also run software for some classic handheld virtual pets, but only from files the user already owns and imports themselves. The app does not include, download or link to any such file.

2. HOW TO USE IT
No account, login or sample file is needed.
- On first launch, tap "Adopt a Tomomix". Tap the shooting star when it crosses the sky, then name your baby (or skip).
- Use the A/B/C buttons, or tap the icons at the top, to feed, play, clean, give medicine and turn off the light.
- Press B with no icon selected to go outside and back in.
- The ⋯ menu has settings, backups and save export/import. Photo and video buttons are at the bottom.
- Premium: on the Tomomix screen, tap ⋯ > "Unlock Premium…". It is one non-consumable In-App Purchase (com.fluorescente.TamaEmu.premium). A Sandbox account works. It unlocks more than one classic pet, Ambient Background, fast-forward, photos/videos and widgets for classic pets, and Live Translation. The Tomomix game itself is completely free, including its widget, backups and save export.
- Classic pets ("Import a ROM" on the welcome screen) need a compatible file the user owns. Reviewers do not need one: everything else in the app works without it.

3. EXTERNAL SERVICES
- Apple StoreKit for the In-App Purchase.
- Live Translation (Premium, optional, off by default) translates on-screen text in classic pets. Offline mode uses Apple's on-device Foundation Models. Online mode sends a screen image to Google Gemini, using the user's own free Gemini API key. The key is stored in the Keychain. I run no server.
- Connect Nearby uses Apple's MultipeerConnectivity, phone to phone, with no server.
- No accounts, analytics, ads or tracking.

4. REGIONS
The app works the same in all regions. The only difference: offline Live Translation needs Apple Intelligence, which is not available on every device or in every region, and Gemini has its own regional availability.

5. THIRD-PARTY MATERIAL
All Tomomix art, characters and sounds are my own original work. The app contains no third-party game software, characters or artwork, and is not affiliated with any toy maker. The classic-pet feature only runs files the user imports, and the App Store description says "Only import files you have the right to use." The emulation code is open source (GPLv3) and credited on the website.
